# Glossaire

- **D+ / D-** : dénivelé positif / négatif cumulé.
- **MNT / DEM** : modèle numérique de terrain, grille d'altitudes.
- **RGE ALTI** : MNT de l'IGN, 1 à 5 m de résolution sur la France.
- **MCP** : Model Context Protocol, standard pour exposer des outils à Claude.
- **OSM** : OpenStreetMap, carte collaborative (source des chemins).
- **Overpass** : API de requête des données OSM.
- **sac_scale** : tag OSM de difficulté issu de l'échelle du Club Alpin Suisse (T1 `hiking` → T6 `difficult_alpine_hiking`).
- **Hystérésis** : seuil minimal de variation d'altitude avant de comptabiliser du dénivelé (anti-bruit).
- **Snap** : accrocher un point au chemin le plus proche.
- **ADR** : Architecture Decision Record, note qui trace une décision technique.
